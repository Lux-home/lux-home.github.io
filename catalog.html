Nút Ảnh & Video mở thư mục Drive của căn; nút Bản đồ mở Google Map. / The Photos & Video button opens the unit's Drive folder; Map opens Google Maps.

Cập nhật từ file của bạn / Update from your file:

  1. Trong KHO_ANH_CAN_HO, sheet DANH MỤC CĂN HỘ → File → Lưu dưới dạng → CSV. / In the file, the apartments sheet → Save as → CSV.
  2. Bấm nút bên dưới, chọn file CSV. / Click the button below and pick the CSV.
  3. Gửi file CSV đó cho tôi để cập nhật cho khách, link giữ nguyên. / Send that CSV to me to update it for customers; the link stays the same.

Dữ liệu nạp ở đây chỉ lưu trên máy này. / Data loaded here is saved only on this device.
